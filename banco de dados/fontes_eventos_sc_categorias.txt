As datas e os locais abaixo foram coletados de páginas de organizadores, instituições,
teatros e serviços de ingresso. Valores que aparecem nas páginas podem mudar.
O banco exige número de vagas; quando o organizador não informa lotação, foi usada
uma estimativa para fins de demonstração. Alguns campos `imagem_capa` usam as capas
genéricas já existentes no projeto para a categoria; os nomes dos arquivos são
referenciados pelo SQL e ficam em `uploads/eventos/`.

IMAGENS
O campo `imagem_capa` guarda somente o nome do arquivo; o site resolve a pasta
`uploads/eventos/`. O SQL usa capas específicas locais para a exposição de Zé Paiva,
Natal em Pomerode, Festival Catarinense de Hip Hop, Sommer Festival, Festival de Forró,
Festival Brasileiro da Cerveja, Animaneco e Mulher Pássaro/TÍMON. Para alguns outros
eventos, o projeto reaproveita as capas de categoria já existentes (`feira_cultural.jpg`,
`danca.jpg`, `festival_primavera.jpg` e `teatro.jpg`), porque as páginas consultadas não
ofereceram um arquivo de divulgação acessível para cada evento.
